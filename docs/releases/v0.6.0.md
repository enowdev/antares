## Antares v0.6.0

### Desktop app
- Antares now ships as a desktop app for macOS (Apple Silicon and Intel), Windows (x64 and ARM) and Linux (x64 and ARM, .deb or .tar.gz). It opens the dashboard of the Antares on this machine, starting it when needed, or of a remote server you pair with.
- Saved connections, device tokens kept in the system keychain, pairing by password or with `antares device pair`, a tray menu, one window per app, and a Reconnecting page when the server goes away.
- The app bundles the `antares` server, so a fresh machine needs nothing else.
- Downloads: https://antares.enowx.ai/#download, or the files below.

### Install
- New one-line installers served from the website: `curl -fsSL https://antares.enowx.ai/install.sh | bash` and `irm https://antares.enowx.ai/install.ps1 | iex`. They find the latest release on their own and check the download against `checksums.txt`. The GitHub CLI is no longer needed.

### Server
- Per-device tokens, stored as hashes and revocable from Settings › Devices.
- A one-time handoff signs the desktop window in without putting a token in the URL.
- `GET /api/version`, and one rate limit shared by sign-in and pairing.

### Migrate from another agent
- Import providers and keys, the default model, persona files, memory, notes (into RAG), skills, MCP servers, schedules, chat channels and roles from Hermes, OpenClaw, nanobot, PicoClaw, CowAgent, QwenPaw, Letta Code, ZeroClaw, NanoClaw and OpenHuman.
- Detect, review the plan, apply with a backup, undo. In the setup wizard, Settings › Migrate, and `antares migrate`.
- Chat history is not migrated. Schedules arrive disabled, and notes that look like credentials are masked and off by default.

### Persona
- Global `AGENTS.md` and `USER.md` join `SOUL.md` in the prompt, edited on the new Agent › Persona page or through `/api/persona`.

### Dashboard
- A new look across every page: IBM Plex Sans, pill controls, rounded surfaces and the red star.
- Custom providers get their own section with an add tile and a header button, and each picks its API format: OpenAI chat, Anthropic, Gemini or OpenAI Responses.
- Hub tabs stay beside the title; Files and Studio scroll their two panes separately.

### Terminal UI
- A new layout: a home screen, a chat box, a composer and a side column with session usage, cost and tabs for agents, tools, skills and the log.
- The transcript shows tool calls as single rows that open into frames, folds runs of read-only calls, and shows thoughts as one line.
- Every shared slash command works in the terminal, and turns waiting on a question or an approval no longer hang.
- Ctrl+P opens a settings menu.

### Command line
- `antares ask` runs one turn for scripts: prompt from arguments or stdin, reply on stdout.
- `sessions`, `skills`, `memory`, `soul` and `logs` subcommands.

### Fixes
- `/remember` no longer overwrites the previous memory.
- `/skills` lists the everyday catalogue instead of the whole security library.
- The terminal UI shows MCP status and matches tool results to the right call.

### Upgrade notes
- Back up `~/.antares` before upgrading.
- The desktop app is not signed with an Apple or Microsoft certificate yet. On macOS, open it once with right-click › Open (or System Settings › Privacy & Security › Open Anyway). On Windows, SmartScreen may ask: More info › Run anyway.
