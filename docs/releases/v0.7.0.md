## Antares v0.7.0

### Dashboard palettes
- Four palettes: **Claude**, **Facebook** (default), **Pinterest** and **Supabase**. Pick one in Settings › Appearance; it applies to every page, including sign-in and setup.
- Light and dark stay independent of the palette, and both are remembered per browser. Stored choices from the older zinc/ocean/forest/violet set map onto the new four.
- Each palette brings its own type and accent, and the fonts are bundled in the binary: the dashboard makes no outbound request to a font CDN.
- A first-paint script applies the saved palette before React mounts, so a reload no longer flashes the wrong theme.

### Chat
- Editing a past message now happens inline in the transcript instead of a dialog. Enter inserts a newline; the send button or ⌘/Ctrl+Enter submits, and clicking outside cancels. The file-change preview and the "revert what changed since this message" option are unchanged.
- The prompt you are reading stays docked at the top of the transcript while its replies scroll, collapsing to a single faded line once it is long.

### Install
- `install.ps1` finds the latest release from the GitHub Releases redirect, as `install.sh` does, and only falls back to the API, so the one-line installer is no longer rate-limited.

### Fixes
- The migration fixture files were never committed: an unanchored `AGENTS.md` rule in `.gitignore` also matched the fake agent homes under `internal/migrate/testdata`, so the migrate golden tests failed on every checkout except the one that wrote them. The rule is anchored, the fixtures are committed, and the skill/memory/role migrations they cover are tested everywhere again.
- `config.Load()` no longer serves a cached config read from a different `ANTARES_HOME`, so changing state directories in-process (and between tests) picks up the right settings.
